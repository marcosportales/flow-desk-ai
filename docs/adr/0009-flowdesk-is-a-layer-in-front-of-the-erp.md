# FlowDesk is an intake and orchestration layer in front of the ERP, not a replacement

The ERP stays the system of record. FlowDesk turns free-text Requests into structured, traceable Tickets and has n8n act on target systems, so swapping a target means changing an n8n workflow, not the app. To show the pattern without real SAP access, the `erp` Category dispatches to a simulated ERP service that creates a record and returns an External Reference stored on the Ticket, with the same idempotency key and Reconciliation behaviour as the notifier (ADR 0005, ADR 0006). Real SAP (OData or the ERP's own API) stays out of scope, as in `docs/plan/PLAN.md`; the README documents how the simulated target would be replaced. Inbound is already covered: any system can submit Requests through the API with its key.
